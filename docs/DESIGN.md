# Pixlings — design

Date: 2026-10-03 · Target: Claude Code ≥ 2.1.287 (Claude Mods GA on 2026-10-01)

## Why this exists

Claude Code shipped Mods two days ago. Research on that day (three independent passes over GitHub,
HN and the mod catalogue) found:

- The biggest open request in `anthropics/claude-code` is **"Bring Back Buddy"** (#45596:
  1,186 👍, 642 ❤, open). The companion people loved is gone, and the ~27 pet mods that tried to
  fill the gap sit at 0–3 stars.
- The one proven audio hit, **peon-ping** (5k★, 1,006 HN points), is shell hooks, not a mod. Mod-native
  sound is empty. `$.audio.play` is silent on Windows and Linux (`claude-code.d.ts:2462`), so
  nobody's mod makes sound there.
- Real, open pains a mod can fix visibly: dead time at the rate-limit reset (#13354, 208 👍),
  not being pulled back when Claude needs you, risky commands sliding past.
- Crowded, avoid as headline: usage/cost/context meters, subagent trees, games, done-chimes.

So Pixlings is one character that carries real utility. The creature is the hero clip; the
utilities are why people keep it installed.

## The product in one line

Hatch a tiny pixel creature that lives above your Claude Code prompt. It watches Claude work,
reacts to tests, commits and risky commands, talks, naps through your rate limit and wakes Claude
up when it resets. It levels up and it is yours.

## Features (v1)

1. **Hatch.** The first session plays an egg that wobbles, cracks and reveals a species with a
   rarity (common 50 %, uncommon 28 %, rare 14 %, epic 6.5 %, legendary 1.5 %) and a 1/64 shiny
   palette. It gets a random name; `/pixling name <name>` renames it.
2. **The band.** An `AbovePrompt` band holds the animated sprite (a `Raster` of half-block cells,
   or an `Image` where the terminal draws images, ~10 fps via `$.ui.blit`), a speech bubble, and a
   line with name, level and XP bar. The `band` setting picks its size (see Band sizes).
3. **Reactions.** Every relevant event maps to a mood, a line and a sound:

   | Event | Source | Mood |
   |---|---|---|
   | prompt sent / working | `prompt.submit`, band `isWorking` | attentive / working |
   | tests pass / fail | Bash `tool.call` result + command match | celebrate / sad |
   | fail → pass | detector memory | "bug squashed" celebration |
   | commit / push / PR | Bash result `gitOperation` | happy |
   | risky command | Bash command before it runs | alarmed |
   | needs permission | `classic.Notification` `permission_prompt` | waving + attention sound |
   | turn done | `turn.complete` | happy (+ OS notification on long turns) |
   | API error | `classic.StopFailure` | dizzy |
   | rate limit | `StopFailure` `rate_limit` + `session.usage()` | asleep with countdown |
   | 90 % of a window | `session.measure` | tired line |
   | petting | `/pixling pet`, band button | love |

4. **Cross-platform sound.** macOS through `$.audio.play`; Windows through PowerShell
   `Media.SoundPlayer`; Linux through `paplay`/`pw-play`/`aplay`. All sounds are original,
   generated by `tools/synth.py` (chiptune synthesis, MIT). Each species speaks its lines in its own animalese voice, synthesized per line by `hooks/lib/voice.ts`.
5. **OS notifications** when Claude needs permission or a long turn ends (Windows toast,
   macOS `osascript`, Linux `notify-send`).
6. **Limit autopilot.** On a rate limit the pixling sleeps with a countdown to `resetsAt`; at the
   reset it wakes up, plays a sound and submits `continue` (opt-out in `/config`).
7. **Progress.** XP per event, levels, accessories unlocked by level (hat, glasses, crown...),
   lifetime stats in `$.store`.
8. **`/pixling`** prints a shareable card (sprite + stats). `/pixling dex` shows the species
   collection. `/pixling hatch` rerolls after confirmation.
9. **Spinner words** themed per species ("Quacking…", "Haunting…").

## v0.2

10. **Vitals.** A row under the name: the prompt cache's countdown, the share of input it served,
    the context window's fill and the rate-limit windows. Each request's counts come from
    `turn.step`; the cache's lifetime is learned (a hit after more than five minutes proves the
    hour-long TTL). A minute before it expires the pixling warns; a cold start is counted.
11. **Tics.** The visible text of each main-thread response is scanned for "You're absolutely
    right", "Great question" and friends; the pixling rolls its eyes and keeps the count.
12. **Badges, streak, recap.** 16 badges earned once from the record, a daily streak, and
    yesterday's work as the first line of the day.
13. **`/pixling share`.** A 240×135 card scaled ×5 to 1200×675, encoded to PNG in-process (own
    5×7 font, own deflate), written through a process's standard input, opened, and a post copied.
14. **Roaming** along the free columns of the band, and an **animalese voice** synthesized per
    line (harmonics shaped by vowel formants), played from standard input.

## v0.3

The research behind v0.3 (2026-10-04): the "Bring Back Buddy" thread had grown past 2,000
reactions, and what its comments ask for is their own named creature with a personality, not
another meter. Claude Code left each person's Buddy in `~/.claude.json` under `companion` (a
name, a free-text personality, a hatch time).

15. **Adoption.** `/pixling adopt` reads that file (`$.fs.read`, else a host process), keeps the
    three fields and drops the rest with the parsed text; the confirmation takes only its exact
    label. `adoptedFrom.hatchedAt` drives the days together. `lib/buddy.ts`.
16. **Personas.** One line per pixling from species- and rarity-flavoured templates, seeded from
    the save so an old save gets the same one every session. `lib/persona.ts`.
17. **Quips, opt-in.** `$.model.complete` with Haiku: 120 output tokens at most, a minute apart,
    never while quiet or away; the prompt is built from counts (`quipEvent`), never from session
    text. The cost is shown beside the line and totalled on the card. `lib/quips.ts`.
18. **Away mode.** `/pixling off|on`, stored, gating every sound, voice, toast, notification,
    auto-continue and drawing.
19. **Reactions.** Native `session.compact` (main loop only) presses the sprite flat and springs
    it back with `tokensBefore/After` when core gives them; `contextPercent ≥ 85` puts a bead of
    sweat on its brow, once per crossing; the `plan_mode` attachment puts on a thinking cap over
    the hat (the hook only observes).
20. **The squad.** `classic.SubagentStart/Stop` add and retire 8×9 minis tinted by agent type,
    drawn in a strip beside the sprite taken first from the walking room; a subagent's tool icon
    goes over its mini. Four stand, the rest are counted.
21. **The cache guard.** `classic.PreModelSwitch` answers `permissionDecision: 'ask'` when the
    cache is warm and `estimated_cache_write_usd` passes $0.25, never headless, from the SDK, or
    over a lower hook's decision. `PostModelSwitch.cache_ttl` fixes the lifetime (stored with its
    source; a learned one is trusted 14 days, a switch's 30).
22. **The room.** A `Pane` (`pixling-room`) on every surface, since `AbovePrompt` is raised only
    in the terminal and the desktop app: home, a dex garden and a badge shelf, laid out from the
    seat's width. `lib/room.ts`. The band gains a hover card (`Box` `hover`, no hook runs).
23. **Heckle, opt-in.** An `AssistantMessage` hook draws the engine's message as received and a
    dim `(¬_¬) #N` under it; N is fixed per message id.

## Architecture

```
plugins/pixlings/
  hooks/register.tsx   wiring: events → brain → state → render
  hooks/lib/*.ts       pure modules, no JSX, runnable under Node for previews and tests
    sprites.ts   species art (16×16 palette grids), palettes, anchors, voices
    canvas.ts    frame composition: body, eyes per mood, accessories, particles, mirroring
    raster.ts    pixel buffer → half-block cells → base64 RasterProps.cells
    band.ts      the band's sizes: form (half blocks, picture, line), fallbacks, the info column
    brain.ts     mood state machine with priorities and hold times
    lines.ts     dialogue bank and templating
    detect.ts    risky commands, test runs, test outcome parsing, limit windows
    progress.ts  rarity roll, names, XP curve, unlocks, stats, revival of old saves
    badges.ts    badges, streak, daily recap
    vitals.ts    prompt cache model and the vitals row
    tics.ts      the model's verbal tics
    roam.ts      walking about the band
    voice.ts     animalese synthesis and WAV encoding
    buddy.ts     reading the retired /buddy's companion, adoption
    persona.ts   template personalities
    quips.ts     the opt-in Haiku quips: request, policy, reply
    room.ts      the room pane and the hover card
    font.ts, png.ts, card.ts   the share card
    platform.ts  sound players, notifications, speech, file writing per OS
  types/index.d.ts     $.state contract
  sounds/*.wav         generated by tools/synth.py
  tests/*.test.ts      claude plugin test (tests/kit.ts: the kit's test with a 20 s default)
tools/
  synth.py           event sounds
  preview.ts         contact sheets of every species and mood
  media.ts, make_gifs.py, hero.ts, make_hero.py, card.ts, voice.ts   README media and samples
```

Rules: `hooks/lib` stays pure (no `$`), so the exact pixels the terminal shows can be rendered to
PNG by Node for the README. Persistent data lives in `$.store`; live UI values in `$.state`;
animation timers restart on hot reload.

## Rendering

A 22×18 px canvas, the 16×16 sprite at (3, 2). Each terminal cell holds two vertical pixels:
`▀` with fg = top and bg = bottom, `▄`/`█` where one or both match, and the terminal's default
background (`0x01000000`) for transparency. 18 px → 9 rows. Eyes, mouth and accessories are drawn
procedurally on per-species anchors, so one body serves every mood.

## Band sizes

`lib/band.ts` decides the band's rows (`bandRows`), and the column beside the sprite fits them.
Quiet, every band keeps its own rows. While it talks it grows to show all the speech, up to
`maxRows`, and past that the speech is cut. Half blocks give the column the rows it needs whole
(`columnRows`), the bubble above the name, XP and vitals. A picture (`compact`, `slim`) talks
from its bottom row up, in lines with a bar on their right: the speech takes the vitals' rows,
then the name and XP share one row above it, and the band grows up only once the speech needs
more rows than the picture has. The sprite stays at the bottom. The one-line band wraps its
speech under the start of the line (`lineSpeech`).

| `band` | Images drawn | No images |
|---|---|---|
| `full` | half blocks, 9 rows | half blocks, 9 rows |
| `compact` | picture, 10×4 cells | as `full` |
| `slim` | picture, 5×2 cells | as `minimal` |
| `minimal` | 3×1 picture on the line | the line with a face |

A band with fewer `maxRows` than its size takes steps down the list, never up. A picture's
cells are worked out on the assumption that a cell is twice as tall as it is wide (the engine
never says a cell's pixels). The frame is padded to that shape and sent as a transparent PNG,
scaled up in whole pixels.

The pixling walks the same spare columns at every size but `minimal`, whose picture sits on the
line. The walker counts in canvas pixels, and `walkScale` converts: 1 per column in half blocks,
2.25 at `compact`, 4.5 at `slim`. So the range and each step stay a column wide, and the strip
widens the picture by those columns. When the scale changes (half blocks becoming a picture),
the walker starts again at home.

The engine says whether a terminal draws images only by refusing a blit to an `Image`
(`the Image draws its alt here: …`), and it refuses that way until its own probe of the terminal
has settled. So a size that would be a picture starts as its fallback, with a 1×1 transparent
`Image` (the probe) beside it, which the frame clock blits once a second. The first accepted
blit redraws the band as a picture. A picture refused with that reason later on goes back to the
fallback and the probe.

The column (`layoutInfo`) stacks the name, the XP bar and the vitals (which wrap to as many rows
as they need), with speech above them. Speech goes in a bordered bubble in a tall band, and in
quoted lines in a short one. When the rows run short, the vitals keep one row, then the name and
XP share a row, then the vitals go, then the name and XP. After that the speech is cut: in a tall
band inside the bubble, keeping the rows below it; in a short one across every row.

## Error handling

Every hook passes `next(e)` through on any failure (`.catch` returns `next`). Sound and
notifications are fire-and-forget from `$.clock.after(0)`, so a missing player never blocks a
tool. A blit that is refused (band collapsed or not mounted) is ignored.

## Verification

- `claude plugin validate` and `tsc` on every change.
- `claude plugin test`: pure-module unit tests plus mounted band tests on terminal and desktop.
- Live: load in a real session through the dev-mods folder.
- Media: frames rendered by the same lib code, never mocked.

## Out of scope for v1

Evolution stages (accessories stand in), multiple pixlings, and an always-on LLM-written dialogue
mode (v0.3 ships opt-in quips instead: rare, short, and priced on screen).
